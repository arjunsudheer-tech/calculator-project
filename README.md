# 🧮 Calculator

A simple calculator built using **HTML, CSS, and JavaScript**. This project allows users to perform basic arithmetic operations through an interactive calculator interface.

## 🚀 Live Demo

https://arjunsudheer-tech.github.io/calculator-project/



## ✨ Features

- Perform basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear button to reset the calculation
- Interactive calculator buttons
- Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 What I Learned

Through this project, I practiced:

- JavaScript functions
- Variables and string manipulation
- DOM manipulation
- Handling button clicks with `onclick`
- Updating content dynamically using `innerHTML`
- Performing arithmetic calculations with JavaScript
- Connecting JavaScript with HTML and CSS
